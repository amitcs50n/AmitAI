# Bounded Realm and SOTOPIA inspection

See [report.md](report.md) for methodology, exact rates, limitations and recommendations. The shortlist locators contain two pending SFW negotiation nominations, not approved training data.

This publication contains analysis, metadata and archived inspection scripts. Raw conversations, cards, public profiles, downloaded upstream files and the full-transcript manual review pack remain in the ignored local directory `data/sft/rp_v1/generated/realm_sotopia_100_20260912/`.

`verification.json` records the original inspection before this documentation publication. Its tracked-file count and git HEAD describe that point in time; hashes of omitted raw artifacts are audit references, not bundled files.

## Script archive

These are the exact one-off scripts used during inspection, not new production adapters or a standalone reproducibility CLI. Do not run them inside this documentation directory: outputs are written beside each script. They require the original ignored working directory, repository-root working directory, existing Python dependencies, preceding source-quality/PIPPA artifacts, downloaded exclusion evidence and the pre-inspection hash inventory. Network collection and the report's manual semantic judgments are separate steps; rerunning a script does not perform a new human review. Consult the report and collection manifests for the bounded retrieval attempts and eligibility exclusions.

The pipeline and configuration remain frozen. Nothing here enables a source, changes provenance, approves rows, launches training or authorizes a larger inspection.
